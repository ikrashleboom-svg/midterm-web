# Sheker Coffee

## Project title and topic
Our project is a website for **Sheker Coffee**, a coffee stand at Astana IT University (AITU). We chose this topic because we all buy coffee there and know the place well.

## Group members
- Azimbek Amandykov
- Meiirzhan Tolendi
- Temirlan Nurshaikhinov

## Short description
This is a website with 5 pages: Home, Menu, About, Gallery and Contact. On the site you can see our popular drinks, read the full menu, find out about Sheker, look at photos of our clients and send a message with the contact form. All pages have the same style, colors and fonts. The site also works on phones and tablets.

## Features implemented
- 5 pages, and the navigation bar is on every page
- Every page has a header (logo and menu made with Flexbox), a main part and a footer with contact info, copyright and social links
- Semantic HTML tags (header, nav, main, section, footer)
- Headings, paragraphs, lists, links and images
- A table on the Menu page
- A form on the Contact page
- One external CSS file (`css/style.css`), no inline styles
- Flexbox for header and menu, Grid for cards, gallery and footer
- Positioning (relative, absolute and sticky) in the hero section and the header
- `:hover` and `:focus` on links and buttons
- `:nth-child()` for cards and table rows
- CSS variables in `:root`
- Google Fonts (DM Sans and Playfair Display)
- `loading="lazy"` for images
- Two media queries (tablet and mobile): the menu goes vertical and the cards go one under another on small screens
- Bootstrap grid (container, row, col) and utility classes (spacing, text, buttons)

## Technologies used
- HTML5
- CSS3
- Bootstrap 5 (we downloaded it and keep it in the `css` folder)
- Google Fonts
- GitHub Pages
